# The Game Table

Browser board games. Open `index.html` to pick a game.

| Game | Folder |
|---|---|
| Ticket to Ride | `ticket-to-ride/` |
| Go-Stop (화투) | `go-stop/` |
| Wahoo | `wahoo/` |
| Chinese Checkers | `chinese-checkers/` |

## Adding a game
1. Put the game in its own folder with an `index.html`.
2. Add an entry to the `GAMES` list in the root `index.html`.
